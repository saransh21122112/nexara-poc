# Nexara AI POC: documentation

| Read | When |
|------|------|
| [`architecture.md`](architecture.md) | You want the big picture: components, data model, deployment |
| [`flows.md`](flows.md) | You want end-to-end behaviour: request to delivery to later changes, state machines, security model |
| [`diagrams/architecture.html`](diagrams/architecture.html) | You prefer to view the diagrams in a browser (open the file locally) |
| [`sdd.md`](sdd.md) | You are about to change something: the spec-driven workflow and definition of done |
| [`specs/`](specs/) | You want to know what each feature is supposed to do and how it is tested |
| [`ui-quality.md`](ui-quality.md) | You change anything visual: the checklist every UI change must pass |

Diagrams are Mermaid, so GitHub renders them in the page. Keep them current: a PR that changes flows, data or architecture updates them in the same PR.
